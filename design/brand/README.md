# 蜡笔皇冠图标（A 版）

- `approved-preview.png`：用户确认的 A 版，珊瑚红蜡笔圆形配左上斜戴皇冠。
- `logo-master.png`：由内置 ImageGen 导出的透明母版，保留蜡笔笔触和皇冠细节。
- `source.json`：导出提示词、文件校验值与各平台尺寸策略。

安装 Pillow 后，从项目根目录运行：

```sh
python3 design/brand/export_icons.py
```

脚本只负责缩放、留白、平台底板和格式编码，不重绘或调色。

Android 自适应前景为 432px / 108dp，圆形和皇冠的实体内容收在中央 54dp 圆内，并校验可见像素不超出 66dp 安全圆。相较安全区满铺，额外留出空间，避免前景显得过大或皇冠被裁切。

iOS 为 1024px、不含透明通道的白底方图，系统负责圆角，图案占画布约 74%。桌面图标为透明圆角白底，图案约占全画布 70%，输出 PNG、七档 ICO 和多档 ICNS。应用内使用独立的透明 Logo，图案约占画布 78%。
